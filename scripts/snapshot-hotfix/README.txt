即梦参考图并发快照热修复 · 2026-11-09

用途：多个分镜同时使用同一参考图时，部分任务报“私有参考图快照校验失败”。
该错误在本地快照冻结时发生，早于本次即梦视频提交。不要把同屏已经生成中的任务全部重跑。

这是单文件源码补丁 R2，适用已核对的 20261107 平台、Claude v3.5 和本轮 v4。
20261107 原文件与 v3.5 仅有一句“火宝素材库／项目素材库”的文案差异，逻辑一致；安装器逐一核对 SHA。
已经成功应用第一份补丁的机器不必再应用，修复后的程序文件完全相同。R2 只扩充可确认的旧版文件清单。
不改 Skill、系统提示词、人物／场景提取、分镜规则、模型参数或即梦协议正文。
不删除图片、历史任务或快照目录，不自动重新提交任务，也不需要重新登录账号。

应用步骤：
1. 正常停止目标火宝服务。保留 data；已交给即梦的任务不要重新生成。
2. 解压补丁，双击 Apply-Fix.cmd，输入火宝源码根目录（含 backend 的那层）。
   或在 PowerShell 中运行：
   .\Apply-Fix.ps1 -ProjectRoot "D:\你的火宝源码目录"
3. 脚本先核对原文件 SHA，再备份原文件，然后只替换
   backend/src/services/jimeng-local-media.ts。
   不同版本文件会拒绝覆盖，以免丢掉其他开发者的修改。
4. 正常启动火宝，只手动重试报本地快照错误的分镜。
   已在生成／已交即梦的分镜继续查询原任务，不要全部重新生成。

旧缓存如果已部分写入，会在下一次明确提交时，使用本轮已验证且同 SHA 的原始图片字节修复。
历史恢复路径仍检查原快照，不会重新读取另一张资产图替换历史任务。

回退：正常停止服务后，将 data/local-runtime/backups/snapshot-atomic-时间/ 中
备份的 jimeng-local-media.ts 复制回原源码位置，再正常启动。保留数据和快照目录。

本补丁用于源码部署；已编译的 EXE 要由开发者重新打包，不能直接替换内部文件。
