# 即梦本地服务接入

本次只新增 `jimeng_local` 视频通道。文字、图片和已有视频通道继续使用原来的流程；系统提示词、Skill、剧本改写、资产提取、分镜生成和项目风格词没有改写。

## 配置方法

1. 先启动即梦本地服务，或已经整合 GPT 与即梦的“创一本地创作中心”。在服务管理页登录即梦、检查账号并选择画布。
2. 在平台“设置 → AI 服务 → 视频 → 新增”中选择“即梦本地服务”。
3. 填写服务管理页提供的 API URL 和 API Key。统一服务使用同一组 URL/Key，不需要额外填写 GPT Key 或即梦 Cookie。服务不在平台这台电脑时，应填写服务电脑的实际 IP 和端口。
4. 获取模型或检查连接后保存。当前通道适配的型号为 `jimeng-2.0-fast`。
5. 进入项目的集工作台，在顶部“视频”选择这条配置。确认分镜的视频提示词和已经绑定的角色、场景、道具图片，再提交单条或批量生成。

API URL 可以填写服务根地址或其 `/v1` 地址。模型目录与连接检查都是只读请求，不会生成视频或消耗即梦积分。检查成功表示接口可连接，不代表平台生成审核或扣费验收已完成。

## 提交的是什么

页面中的“视频提示词”仍由平台原来的流程生成。平台保留原有项目风格词拼接，然后把完整文字、时长、画幅及实际参考图片转发到即梦服务。即梦通道只做图片传输和原生 `@` 引用绑定，不重新编写镜头内容。

角色名称、场景地点、道具名称与图片保持成对、保持顺序；`@母亲站A`、`@母亲从桌边拿起空杯` 等名称后直接接动作的写法不需要人为插入空格。已绑定的名称重叠时按完整名称最长优先解析。无法唯一确定的同名图片或缺失引用会提示修正，不会用另一张图代替。

本轮提交前会保存提示词哈希、请求 UUID 和参考图原始字节快照。排队期间换掉资产图片不会改变已经提交的这一轮。图片不会被压缩成缩略图，也不会因数量超过上限而静默截断。

## 可设置的参数

此接入支持文字和参考图片，执行时长为 1–15 秒整数，可选择 16:9、9:16、1:1 画幅。分辨率由即梦画布及平台实际执行决定，不将其他视频模型的分辨率选项冒充即梦可控参数。

参考图的本地保护范围为最多 8 张，PNG/JPG/WEBP，单张不超过 10 MiB、总计不超过 35 MiB。当前接入不支持首尾帧、参考视频、参考音频或平台的角色音色引用；遇到这些内容会明确拒绝，不会静默丢弃。以上为本接入的保护范围，不代表即梦官方上限。

## 排队、失败与成片

即梦服务串行准备和提交消息；上一条接单后继续提交下一条，不等待上一个视频渲染完成。平台内部仍可能排队；没有真实百分比时只显示阶段。

生成可能持续很久。服务与平台保留原任务号，在后台继续查询；提交结果不确定时只按原请求 UUID 查回，不自动再次生成。重新启动后仍查询原任务，不把“恢复”当作重新扣费生成。

平台明确返回参考图违规等失败时，平台显示该轮任务失败及原因。分镜以前的视频仍可预览，但不会将旧视频当作这次任务成功。

即梦接单且画布卡片命名后，平台显示“已交即梦 · 待回传”。出片后平台每 10 分钟自动回传一次，也可以在剧集页点“回传视频”；回传只查询和下载，不重新生成，分镜已有更新的任务时不覆盖。生成是否完成和视频是否已经下载是两件事。

## 更新与数据保留

平台源码与即梦服务分别更新。更新前停止对应程序并备份；按文件覆盖程序，不删除旧数据目录。平台保留 `data` 与自己编辑过的 `backend/workspace`；统一服务保留根 `data`、`engines/gpt/data`、`engines/jimeng/data` 和 `网络设置.json`。单独即梦服务保留其 `data` 和网络设置。

本次源码不包含账号、Cookie、API Key、素材或任务历史。服务端配套更新也不包含这些内容。
