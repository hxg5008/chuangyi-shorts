# 2026-11-09 风格提示词详情更新

补齐风格选择器中缺少完整提示词查看的问题。原弹窗只显示名称和简介，管理员设置中能看模板，选择卡片时看不到。本次修改仅涉及前端详情和发布标识，不改变风格内容、生成流程、Skill、模型参数或资产／分镜规则。

## 新界面

- 打开风格库、单击任意卡片，右侧直接显示风格库详情：名称、来源、分类、适用步骤、库版本、完整简介和完整提示词。
- 优先显示 API 返回的完整 `template`，保留原语言、前后缀、换行和 `{content}`；旧单段风格完整显示原 `prompt`。
- 文本框只读，长提示词独立滚动；复制全文不采用风格。局域网 HTTP 浏览器无法自动使用剪贴板时，选中文本并提示 Ctrl＋C。
- 单击预览、取消、复制都不修改已采用值；原“采用风格”按钮继续负责明确选择。
- 复制完成前切换卡片、关闭或模板刷新，不会让迟到结果污染新详情状态。
- 小屏时详情转到网格下方，外层弹窗限制在视口内，底部采用按钮继续可见。
