## 本次修正

- 系统界面基础图只保存可跨集复用的材质、配色、边框、布局、空白信息槽位和无文字抽象图标；标题、消息、按钮、数字区全部留空，不把当前集台词、奖励、任务、金额和等级固化进去。
- 系统界面专用设计模型不再收到本集原文、分类证据、旧样貌／服装、旧人像提示词或旧界面消息。具象化身保留其形态依据，普通项目继续原人物路径。
- 手写、已保存、缓存、重新生成以及风格拼接后的最终系统底图提示词共用检查；明显正向填写文字或数值的指令会明确拒绝，不静默改写用户提示词。
- 新增基础图规范版本。旧提示词、旧图片、采用记录和任务历史保留；没有新规范的旧图需先查看、确认是无本集文字／数值的通用空槽界面，才可明确采用。程序没有 OCR、擦字或自动修图。
- 系统底图参考图片必须是当前已核对且规范一致的采用图；未核对的截图、其他 URL 和旧有字底图不会静默放行或被悄悄删掉后继续计费。
- 新图片任务带基础图规范快照，旧版本晚到结果不能自动覆盖当前采用。后台恢复继续关联原任务，未自动重发提示词或图片请求。
- 视频制作新增“本镜界面文字”。只有系统模式且实际绑定界面型系统的分镜显示；原文显示依据只读，用户内容每行一条，显式保存独立元数据，不调用模型。
- 系统说话不自动转成界面文字。本镜原文明示的屏显内容可按证据使用；用户另行填写的内容只作用于当前分镜。清空只取消自定义，不删除原文明示显示内容。
- 本镜文字保存后需要用户明确重新生成本镜提示词才能应用，已有视频和原任务不变。旧宽松视频提示词保留，新提交若与本镜授权冲突会要求核对／重生成，未静默重写或自动重发视频。
- 本镜设置核对原文、绑定系统与表现版本，活动视频／分镜／相关批次有写入保护；旧页面的晚响应不能把授权写到另一镜头。

**规则保护范围：**原 44 份 Skill／系统提示词文件、20 个 Agent 工具输入 Schema 和 2 个主要分镜 Schema 保留原文。新增辅助服务、条件边界和独立元数据接口，未替换普通项目的提取／生成规则，也未新增对所有剧本生效的系统流程。程序并非完全没有新增行为：系统模式的底图内容隔离、图片兼容性、屏显授权和新视频提交前检查均为本轮新增逻辑。

详细使用、API、维护位置、旧图处理和验证边界见《2026-11-09_系统底图与本镜文字分离.md》。

## 更新现有 Windows 源码部署

1. 正常停止原火宝，另存整个旧程序目录；至少保留完整 `data`、实际可编辑 workspace、`backend/.env` 与网络配置。
2. 将累计包解压到单独目录，找到同时包含 `backend`、`frontend`、`scripts` 的火宝程序层。
3. 将该层程序内容覆盖旧火宝根目录，替换同名程序文件；保留原数据、账号、Cookie、Key、作品与网络配置，不删除旧目录、不再迁移一遍账号。
4. 本轮同时更新前后端，不能只替换一个 Vue 文件。没有新增 npm 依赖，辅助元数据由程序初始化。
5. 正常启动后 Ctrl＋F5，通过 `/api/v1/health` 与随包收据核对本次版本，避免只凭文件夹名称判断。
6. 普通项目先检查原流程；系统项目检查旧图需核对标记、底图提示词、当前采用和本镜界面文字，再由用户选择少量真实模型验收。

本轮仍是火宝侧更新。已使用配套一体执行平台 1.2.0 的机器可以保留当前平台，不因本轮空白底图与屏显设置重复迁移。若累计总包附带平台目录，该目录沿用既有核验版本，不宣称平台也随本轮改版。

## 验证与回退

没有真实付费模型、实际即梦成片或 OCR 验收。中文文字渲染、无字底图的实际模型遵循程度和视频声音／屏显效果仍需真实验收；本轮不承诺任意模型每次输出都完全一致。

回退前正常停止服务，另存升级后产生的新项目、任务、图片和本镜设置，再恢复同一备份时点的程序、数据库和配置。原 v4.4 发布包与 SHA 继续保留；本轮改动前的代码备份由外层交付记录注明，不能将代码备份误当成用户服务器生产数据备份。

前序累计说明、系统模式与资料补齐说明继续保留；本轮文档专门补充空白底图与本镜文字分离，不覆盖历史交付记录。
