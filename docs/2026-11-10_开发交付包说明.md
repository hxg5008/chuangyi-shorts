# 开发交付包：火宝 v4.3.5 ＋一体执行平台 1.3.1

本次整理为一份可给其他开发继续维护的交付包。最终版本包含 v4.3.4 的用户账号授权、项目画布选择、绑定版本和批量快照，并补齐本次“删除项目画布绑定”及火宝兼容保护。

## 包内目录

- `01_源码`：火宝完整源码 ZIP、一体执行平台源码目录。保留许可证、锁文件、模板和测试，不含 node_modules、实际账号或作品。
- `02_部署包`：一体执行平台 Windows 便携包，以及火宝＋平台双端累计程序覆盖包。运行时只放一份，不重复附带各旧版本。
- `03_文档`：开发接手顺序、本地启动与构建、架构与代码导航、账号画布接口及迁移、测试与已知边界、历史交付记录和本轮说明。
- `04_验收`：最终机器验收汇总、前后端测试的脱敏副本、协议和核心文件完整性报告，以及真实页面的隔离测试截图。
- `05_校验`：逐文件清单、来源及版本信息。根目录的验证脚本只读检查文件 SHA-256。

## 本次追加的删除绑定

一体平台“项目画布绑定”新增删除按钮。删除只停止绑定的新提交并从普通列表隐藏；已有 Key 可继续查询和下载原任务。远端画布、视频、文件和历史归属保留。

排队或正在本地提交时返回 409，不自动取消任务。删除后不能重新启用，也不能把原画布分配给其他用户。用户需在火宝为后续任务选择新的绑定。火宝对新请求检查远程绑定状态，旧任务恢复函数继续使用旧版本。

## 交付保护

包内不包含生产 data、真实 .env、Cookie、API Key、GPT 登录态、账号资料、作品、任务库和私有备份。完整便携包只有未登录的运行环境，首次启动由部署者自行配置。

已有服务更新前正常停止并完整备份，分别覆盖程序，保留 data、workspace、环境和网络配置。不删除原程序目录，不重新做账号迁移。旧版程序不理解多版本绑定和删除标志，回退需要先保护新增数据后按备份方案处理。

最终校验结果见包内 `04_验收/最终验收汇总.json`。没有将本地协议编译通过写成所有上游服务已经真实付费验证；本轮新增功能采用隔离数据库、假账号和假模型服务测试。

本机原代码及历史版本包保留；开发交付包是独立副本，不替换现有运行数据，也未自动部署远程服务器。
