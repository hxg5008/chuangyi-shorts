## 请求日志

新增 `platform_request_logs`，不以逻辑任务或 SDK 轮次冒充一次出站调用。唯一底层 HTTP observer 覆盖文本、图片、视频、查询与下载，额外接上原来一处裸 fetch 的引用读取。请求记录关联业务任务、模型轮次、尝试编号、发起用户、项目所属用户、项目、集数、渠道和配置。

异步媒体任务保存发起人快照，后台派发／恢复沿用；历史缺失发起人不按项目 owner 冒充。默认列表只展示模型调用，查询、上传、下载可通过阶段筛选查看；子请求关联到生成请求。没有真正发出的本地检查错误继续留在原任务中心，不伪造 HTTP 记录。

管理员 API：

- `GET /api/v1/admin/requests`：服务端筛选、分页、统计与选项。
- `GET /api/v1/admin/requests/:id`：详情与关联请求。
- `GET /api/v1/admin/requests/export`：当前筛选摘要 CSV；超过 10,000 条明确拒绝并要求缩小范围，不静默截断。
- `GET /api/v1/admin/requests/:id/export`：单条 JSON。

普通用户不能访问以上接口。原任务中心和 AI 实况保留，不合并成全用户页面。列表不读取完整报文，详情按需读取；请求成功与上游业务状态分开。重启时未完成观察的连接标为待核实，不自动重发生成。

## 传输与脱敏边界

只观察实际发送参数的副本；响应使用按需拉取透传流，不提前抽干、不双重读取、不增加重试。`highWaterMark=0`，取消传给原 reader；URL、redirected、type 及 clone 元数据保持原语义。观察或存储失败不替换业务的原成功结果或异常。

请求和响应每份日志正文最多 256 KiB，截断或省略明确标记。媒体字节不写日志；FormData 先固定字段序列，同名 image[] 每项分别保存描述，文件流式计算摘要，64 MiB 总哈希预算外明确省略。

凭证脱敏覆盖 headers、重复 query、结构化 body 和响应回显，并在派生 ID／model／业务状态元数据出口再过滤。超长非结构化响应不留下可能是凭证前缀的原文尾片段；敏感 header 先收集值再生成副本，未知 header 默认隐藏。隐藏思考内容排除，合法请求中的思考配置参数保留。

`headers_ms` 表示响应头返回等待；`ttfb_ms` 是消费者第一次读取数据块的观察时间，UI 明确标注客户端观测，不宣传为网络抓包 TTFB。只显示实际返回的 Token，不补 0、不估算积分或费用。
