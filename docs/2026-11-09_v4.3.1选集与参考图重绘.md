## 页面内直接选集

顶部集数位置改为紧凑选集菜单，显示集数和标题；真实集号按数字排序，上／下一集以实际列表定位，缺号不会进入不存在的集。

页面按项目 ID＋集号重新创建，保留原文、AI 改写、资产、视频或导出所在阶段。离开旧集即释放旧轮询和迟到回写，后台已提交任务继续运行；后续 refresh 不再抢占用户选择的面板。

未保存原文、剧本、资产、声卡和参考图先确认；保存或上传过程中禁止切集。文本编辑增加字段级 pending／revision：成功才推进服务器基线，失败保留草稿；旧 GET 迟到不能覆盖刚保存内容，同字段连续写串行且同值合并。没有改写模型消息、提取指令或生成工作流。

## 手动参考图重绘

单集资产制作和项目素材库的详情弹窗共用 `AssetImageLibrary.vue`，支持角色、场景、道具。用户可改最终提示词、上传参考图，或明确点击“用当前图作参考”。临时参考只作用于本弹窗手动重绘，不自动带入卡片、批量生成，关闭重开也不设为永久默认引用。

手动分支：保存用户明确确认的最终提示词，按点击时冻结的图片模型／参数提交原文和选中参考图，不调用文字模型重写，不再次拼接项目风格或场景构图段。普通卡片、批量和自动出图沿用原 v4.3 流程及默认采用行为。

参考图片校验 PNG／JPG／JPEG／WEBP 实际格式、像素、文件大小与项目访问权限；每张 30 MB、合计 35 MB，张数按模型声明与已适配传输分支收紧。超限、不支持、文件损坏、配置变化和越权均在提交前明确失败，不截断或悄悄转成纯文生图。

参考图保存为项目内 SHA 内容地址快照。完整临时文件落盘后才原子发布；只链接本程序写好的临时文件，不链接用户可变源。任务数据库只存路径、SHA 和来源，执行前再验证并转换为真实字节传给图片接口，避免把多张 base64 反复写入 SQLite 和日志。逐级校验父目录，拒绝 Junction／路径跳转。

同素材的重复手动点击只创建一条活动生成任务，不限制其他素材按现有并发设置执行。

## 历史和当前采用

新增附加 `asset_image_versions` 表，首次使用历史／生成相关功能时创建。每个素材独立保存版本；旧当前图、旧任务结果按需补入，兼容只填写 `local_path` 的旧记录。一次任务多张结果分别留存，不按 task ID 错误压成一张。

详情手动重绘有当前图时只新增历史，不顶掉已采用图；首次无图时可自动采用。历史显示真实生成／上传时间、实际像素尺寸、当前采用、缺文件／外部变化状态，未知旧时间明确显示未知，不从文件 mtime 伪造生成时间。

采用经过文件校验和事务 CAS；当前图不能删除。删除历史是软删记录，**不物理删除可能被旧任务／视频引用的文件**，UI 删除确认已说明。删除后不会被下一次 backfill 恢复；删除资产后，迟到生成只保留任务结果，不重建资产。上传替换也保留前图。

原图查看默认 100% 原始像素与原比例，可滚动查看大图，也可切适应窗口。旧历史 GET、采用 POST、上传、保存和切换素材之间增加状态序列隔离，迟到 GET 不得把当前采用回滚为旧图。

### 两份旧测试的目录隔离修复

最后逐表数据核对发现，最初两轮全量回归中的两份旧 SDK 离线测试未设置独立数据目录，向本机实况表追加了 30 个无用户／项目归属的合成任务和 88 个事件。其标题与两个精确测试时间窗一致；所有原有行、项目、素材、账号等业务表均未改动。

先另存 `private-data-backup/after-test-before-log-cleanup.sqlite3`，再在事务内核对全部原始表和记录，只移除本轮精确识别的任务／事件，恢复对应活动事件 sequence；43 个表的全行摘要与改动前一致。**没有还原整个数据库或回退用户资料。** 证据为 `TEST-ACTIVITY-CLEANUP.json` 与 `PRODUCTION-DATA-PRESERVATION.json`。

随后修复 `agent-text-stream.test.ts` 与 `guarded-agent-sdk.test.ts`：第一条 import 即设置独立 TEMP 的四项数据路径，业务模块载入后再验证解析路径与实际 SQLite 文件，错序会在用例前失败；另有外部哨兵 canary 验证没有写出隔离目录。只改测试和 helper，不动生产业务逻辑。最终全量重跑后再次逐表核对结果写入验收回执。
