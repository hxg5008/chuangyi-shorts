## 现有火宝更新步骤

1. 正常停止旧火宝服务。将整个旧程序文件夹另存一份；至少保留完整 `data`、实际 workspace、`backend/.env` 和 `network.json`。不要删除原程序目录。
2. 解压累计更新总包到单独目录。打开 `01_创一剧坊累计更新`，这一层能看到 `backend`、`frontend`、`scripts` 等文件夹。
3. 把这一层全部文件复制到旧火宝根目录，选择替换同名程序文件。例如用户现有目录：`D:\项目\huobao-source-20261107-platform`。不要把 `01_创一剧坊累计更新` 整个文件夹再套进旧目录。
4. 本覆盖包不含 `data`、真实 `.env`、网络 JSON 或可编辑 workspace。正常覆盖不会删除旧数据和账号。原有依赖可继续使用，本轮没有新增 npm 依赖。
5. 配套执行平台更新并启动后，再启动火宝，浏览器按 Ctrl＋F5。健康接口 `/api/v1/health` 的 `release` 应为 **`20261109-platform-v4.2-production`**。

## 一体平台更新

总包内 `02_一体执行平台累计更新` 是配套 Windows 程序覆盖目录，已剔除 `网络设置.json` 和所有 `data`，避免覆盖现网配置。

1. 正常停止原一体平台，备份其整个程序目录。
2. 打开 `02_一体执行平台累计更新`，这一层可见 `启动服务.cmd`、`src`、`runtime`，把内容复制覆盖到旧一体平台根目录。
3. 保留旧平台完整 `data` 和 `网络设置.json`。不删除数据、不重复迁移、不重新导入 Cookie 或登录 GPT。
4. 使用原网络设置启动；按本包文档更新不会自动重发历史任务。

已经使用 1.2.0 的机器可保留现有平台程序，只更新火宝。
