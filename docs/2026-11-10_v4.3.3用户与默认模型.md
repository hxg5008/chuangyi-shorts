# v4.3.3 开发交付：用户删除、默认模型、模型编辑界面

本轮在 `huobao-source-20261109-platform-v4` 的 v4.3.2 基础上继续修改。新版本标识 `20261110-platform-v4.3.3-production`，不更新一体执行平台。

## 改动及数据边界

1. 用户列表增加删除。后端采用可审计的逻辑删除：撤销会话、移除指定模型授权，保留 ID、作品和历史。旧用户名可重新注册，但新 ID 不继承任何数据或权限。有运行／待派发任务返回 409；禁止自删和删除最后有效管理员。
2. 复用既有 `ai_service_configs.is_default` 设置三类默认。事务内只清同类型旧默认并设置新默认，不改优先级。权限过滤在先，默认排序在后，明确选择和已锁定剧集优先。新剧集按当前默认初始化，旧剧集不迁移。
3. 模型编辑由窄侧栏改为居中 1120px 自适应弹窗，固定头尾与滚动正文。协议选择使用可搜索列表＋详情，展示真实协议 ID、来源、插件版本和已声明能力。保留原类型、权限、能力、参数，不添加未实现的积分定价界面。

新增 API：

- `DELETE /api/v1/admin/users/:id`
- `POST /api/v1/admin/channels/:channelId/models/:modelId/default`

启动迁移仅给 `platform_users` 增加可空 `deleted_at`、`deleted_username` 和索引。保留原 ID、外键及用户名历史投影。生产库在本轮未启动迁移、未删除账号；测试在隔离目录运行。
