# 即梦用户画布管理验收记录

交付：创一剧坊v4.3.10，一体执行平台1.4.0。日期：2026-11-11。

## 完成范围

- 管理员全局控制即梦功能权限，账号池仍可限制到指定用户。旧通道不能绕过新功能权限。
- 用户在项目中选择已有画布、新建并输入名称、同步修改画布名称；界面改为“当前画布／切换画布”等直接文案。
- 管理员可一次性确认并接入旧版历史画布。已有其他项目归属的画布不会被重新分配；旧无路由任务不改归属、不自动授权给新项目Key。
- 新任务在异步准备素材前固定执行路由；切换之后，已固定路由的排队任务继续使用原画布，原历史不挪动。
- 创建失败继续使用原请求编号和原名称；不明确的远端结果不重发。两项目竞争同一空闲画布时，仅释放已被证实失败且无任务引用的占位。
- 改名先读原名、提交真实接口、回查确认。重复确认已生效改名作为幂等成功处理，失败不谎报已同步。
