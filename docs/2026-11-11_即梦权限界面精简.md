# v4.3.11 / 一体平台1.4.1：即梦只保留功能授权

管理员页面现在只保留两部分：服务连接，以及“谁可以使用即梦”。不再显示旧版绑定维护、接入历史画布、账号/画布逐项授权、默认账号下拉或单独新建权限开关。

保存全局功能权限后，获准用户可以在项目视频页选择已登录账号、使用未分配的已有画布、新建画布和改名。不再受以前隐藏的账号/画布授权限制。旧授权数据不删除，未配置新功能权限的旧安装维持兼容。

用户已明确允许：获准用户可自行选择尚未归属任何项目的旧画布。因此旧版无路由历史画布会出现在列表，无需管理员逐张确认；选择后自动建立后续任务的项目归属。已属于别的用户/项目的画布及删除墓碑仍不可占用，原任务不搬移，不把旧的无路由历史任务授权给新项目Key。

原画布还有旧版本地排队、提交中或结果未明确的任务时，暂不能接入，提示等待或选择其他画布。已稳定接单并在云端生成的任务不要求等到最终出片。同账号其他画布不受影响。平台拒绝接入后会安全释放尚未建立、无任务引用的本地占位；网络结果不明仍保留原记录核对。

失败后的继续操作沿用原用户/项目/账号/画布与请求编号；远端路由已建立而Key返回失败时，不另建路由。旧版本待处理选择会补充安全接入标记后继续原操作。

新功能权限为全局约束。未启用项目画布的另一条即梦模型，不能借旧默认账号通道绕过隔离；会提示管理员保存服务连接。

## 使用

1. 管理员选择视频服务，检查连接并保存一次。
2. 在“谁可以使用即梦”选择全部或指定用户，保存。
3. 用户在项目视频页直接选择账号和画布，或者新建/改名。

## 更新

两侧同时更新：工作台v4.3.11、一体平台1.4.1。保留data、网络配置、workspace及运行依赖，不重新迁移账号或Cookie。平台1.4.1新增`safe_legacy_adoption`能力标志；旧平台不具备安全接入检查时，工作台会提示升级。

本版未修改Skill、系统提示词、提取规则、分镜规则、视频提示词或项目风格。只改变功能权限、画布选择/接入及管理界面。验证使用隔离数据和模拟即梦传输，未提交真实付费任务。
