# 创一剧坊 v4.3.1：直接选集与手动参考图重绘

本版在已回退的 v4.3 基础上增加选集导航、手动参考图重绘和独立图片历史。保留 v4.3 的风格、导入、运行看板、出现集数、模型渠道和即梦接口；不重新加入时期母版／衍生角色、系统模式或资料补齐规则。原 44 份 Skill／系统提示词保持不变。

## 直接选集

单集工作台顶部的集数位置可选择本项目其他集，也可使用上一集／下一集。列表按实际集号排序，缺号不会跳进不存在的集。

从资产制作切到下一集仍停留在资产制作；从视频制作切换也保留当前阶段。切换时重新加载目标集数据并结束旧页面的轮询，不中断后台已有生成任务。存在未保存编辑时会先提示，上传或保存过程中不切换。

## 带参考图手动重绘

在单集资产制作或项目素材库打开角色、场景或道具详情：

1. 检查或编辑“最终提示词”。手动重绘直接使用此处正文，不再调用文字模型重写。
2. 可上传自己的参考图片，也可点击“用当前图作参考”；参考图可选。
3. 点击详情弹窗中的重绘按钮。使用当前所选图片模型，提交最终提示词和明确选中的参考图。
4. 新结果进入“历史图片”。预览满意后点击“采用此图”，才替换该资产当前用于后续创作的图片。

参考图仅用于本次详情窗口里的手动重绘，不会自动混入卡片或批量生成。关闭窗口后不会把临时参考图当成永久默认参考。模型不支持参考图或超过张数时会明确提示，不会悄悄丢图继续提交。

## 图片历史

角色、场景、道具各自保存图片版本，显示生成／上传时间、实际尺寸和“当前采用”。历史图可查看原图、采用或删除记录；为保留旧任务和视频的引用，删除历史记录不直接删除物理文件；当前采用图不能直接删除。采用只更新当前素材指针，不重新生成，也不改写已提交任务和已生成视频的素材记录。

旧资产在首次使用历史功能时登记已有图片，不要求重新提取资产。用户手动重绘期间原图继续保留，刷新页面和并发生成不应让迟到结果覆盖用户明确采用的图。

## 更新已有 Windows 源码部署

1. 等待在途任务完成，正常停止火宝；另存完整原目录，至少备份完整 `data`、实际 `backend/workspace`、真实 `.env` 和 `network.json`。
2. 将 `chuangyi-platform-v4.3.1-cumulative-update-20261109.zip` 中的内容覆盖到原程序根目录，同一层应能看到 `backend`、`frontend`、`scripts`。不要先删除原目录。
3. 覆盖包不含用户 data、账号、模型密钥、网络设置或可编辑 workspace，不新增 npm 依赖。新增历史记录表在首次使用相关功能时自动创建，保留已有表与素材。
4. 启动火宝并按 Ctrl＋F5；`/api/v1/health` 的 release 应为 `20261109-platform-v4.3.1-production`。

一体平台仍可使用现有 1.2.0，不需更新或重新迁移账号。新电脑应使用完整源码 ZIP 并按首次部署说明安装依赖，不能只用覆盖包空目录启动。
