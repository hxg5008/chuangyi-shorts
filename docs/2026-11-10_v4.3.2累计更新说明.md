# 创一剧坊 v4.3.2：统一后台与请求日志

本版基于 v4.3.1，保留选集、参考图重绘、图片历史、风格和导入等已有功能。本次整理管理员配置入口，并新增实际出站请求日志；不修改 Skill、系统提示词正文、资产提取或分镜规则，也不增加模型重试。

## 管理入口

顶部保留“项目、任务中心、管理后台”。管理员的全局配置集中到管理后台：

- 模型与服务：模型渠道、模型试用、一体平台。
- 创作配置：风格库、Agent 与 Skill、创作默认设置。
- 用户与运行：用户与权限、请求日志、存储管理。

旧 AI 服务编辑页下线，现有渠道、配置编号、模型参数、项目与剧集绑定保留；工作台继续使用兼容的模型读取接口。旧 `/settings` 链接按原 tab／section／hash 跳到对应后台页。

界面固定使用中文，顶部不再显示语言切换，浏览器以前保存的英文等界面偏好也不会导致显示外文。主题仍使用顶部入口。AI 默认内容语言是独立设置，只在管理员“创作默认设置”里明确保存；本次界面调整不改变原来保存的值。

Agent 与 Skill 页面使用原来共享文件和 API，只搬入口，不自动重置或改写。存储页仅提供当前部署支持的功能：纯网页主要查看服务端目录／容量；原桌面版迁移入口仍受桌面桥能力约束。

## 任务中心与请求日志

任务中心继续按创作任务展示进度和结果。管理后台“请求日志”单独列出启用本版后实际发出的 HTTP 调用，可筛选时间、用户、模型、渠道、文图视频、阶段、状态和关键词；筛选和分页在服务器执行。

列表默认只看模型调用，可通过阶段切换查看查询、上传、下载等。每次实际调用有自己的日志 ID，关联业务任务、模型轮次、尝试次数、上游请求号和上游任务号；不把这些编号混成同一个 ID。

点击记录打开详情：请求概览、最终出站参数的脱敏副本、响应内容、关联过程、时间和用量。列表不读取完整报文，详情按需载入。仅显示实际返回的 Token，未知显示未提供，不推算积分或费用。

HTTP 成功只说明该次调用成功，不保证视频已经完成。生成、查询、下载分别记录；重启时未完整观察的请求标为“结果待核实”，不会因此重新生成。历史任务仍可在任务中心查看，未采集过的原始请求不会补造。

普通用户不能访问管理员请求列表、详情和导出；后台另外记录真实发起人及项目所属人，管理员代用户操作时不把项目所有者冒充发起人。

## 记录范围与限制

- 日志仅观察副本，不改变实际请求内容或响应字节，不增加重试。
- 流式响应在原消费者读取时观察，不提前抽干或双重消费；“响应头等待”与“首块读取（客户端观测）”分别展示，后者不是网络抓包 TTFB。
- 请求／响应日志总正文上限为 256 KiB；超长内容明确截断或省略，不影响原始请求。媒体文件不写入日志，只记录每个文件的顺序、类型、大小和可用 SHA；哈希有独立预算，省略会说明。
- Key、Cookie、签名、敏感 Header、已知凭证回显和隐藏思考字段过滤。日志没有完整凭据；请求正文与派生 ID 等元数据都需经过脱敏。
- CSV 导出当前筛选，超过 10,000 条会要求缩小范围，不静默截断。导出进行了 CSV 转义和公式前缀防护。
- 日志自身保存失败不会替代模型成功结果或原错误。没有发出的本地校验失败继续在原任务／AI 实况里展示，不伪造 HTTP 请求。

## 更新步骤

1. 等待在途任务完成，正常停止火宝；备份完整 data、workspace、真实 `.env` 和网络配置。
2. 解压 `chuangyi-platform-v4.3.2-cumulative-update-20261110.zip`，将内容覆盖到原程序根目录。不要先删除原程序目录。
3. 覆盖包不含 data、真实 `.env`、网络 JSON、可编辑 workspace、账号或临时测试 Key，不新增 npm 依赖。
4. 启动并按 Ctrl＋F5；健康接口 `/api/v1/health` 的 release 应为 `20261110-platform-v4.3.2-production`。

已有一体平台 1.2.0 无需重新迁移账号。新电脑应使用完整源码包并按首次部署说明安装依赖。

完整测试计数、原规则文件校验、当前数据保留和 ZIP 文件摘要以随交付的验收回执为准。此次只改本机源码，没有自动更新另一台服务器。
