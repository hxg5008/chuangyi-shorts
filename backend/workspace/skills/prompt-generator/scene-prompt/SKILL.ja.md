# シーン最終プロンプト（横長の四視点画像 · 人物なしの空カット）

**16:9の横長キャンバスを等大の2×2に分割した1枚の参照画像**を生成し、**各枠も16:9の横長**にする。最初の3枠は同じ空間を異なる方向から見た明瞭な広角エスタブリッシングショット、右下枠は90度の垂直俯瞰とする。4枠は同じ時刻の同じ空間で、**完全に人物のいない**空カットとし、**前景、中景、後景、出入口、床、壁、および主要な調度品の固定的な相対位置**を維持する。空間構造は連続し、自己完結的で再利用可能でなければならない。

この画像はそのシーンのすべてのカットの背景参照アンカーとなる：観客もモデルもこの1枚から空間全体のレイアウトを読み取れなければならない——どこから出入りするのか、床と壁はどんな質感か、中核となる調度品がそれぞれどの位置に固定されているか。視点は安定していて汎用的でなければならない。

## 読み込みと継承

`read_scenes` を `{}` で呼び出し、指定された `scene_id` の `location`、`time`、`prompt`、`lighting`、`final_prompt` を読む。シーンID、元の資料、プロジェクトの画風、他のアセットは変更しない。

元の資料と、実際に参照できるユーザー確認済みの単画像プロンプトから、空間、照明、色、素材、写真表現、雰囲気の有効な記述を引き継ぐ。競合する単画面構図、画幅、指定ラベルの禁止だけを置き換える。取得していない元画像や、上書きされて読めない過去のプロンプトを読んだと主張しない。

光源と方向、色温度の寒暖、強弱、明暗対比、影の硬軟、反射、色彩、素材感、自然な被写界深度を保つ。元の窓格子の投影、暖光、暗部の階調は具体的に残し、単なる「自然光」に要約しない。元にない効果や一律の金色の光を追加せず、フラットな照明、建築線画、ミニチュア、別のレンダリング様式に変えない。視点による受光面と遮蔽の変化は許すが、物理的な光源を移動・再配置しない。

画幅は全体も各枠も16:9横長に固定し、実際のピクセル寸法はバックエンドが設定する。画像モデルと品質は既存の設定を維持する。ツールに未定義の寸法や参照画像パラメータを渡さない。

## 四視点の配置

- 左上枠「正向视图」：主な入口または既定の正面方向から主体空間を見る。確認済みの前景構図と奥行きを引き継ぎ、調度品を移動しない。
- 右上枠「45度斜侧视图」：同じ空間内で側方に移動し、正面に対して約45度から観察する。通路、壁、扉、窓、調度品のつながりを示し、画面そのものは傾けない。
- 左下枠「反向视图」：反対側から入口方向を見返す。正面の鏡像ではなく実際の背面関係を示し、見えなかった側を再設計しない。
- 右下枠「90度垂直俯视图」：真上から垂直に見下ろす。家具、扉、窓、通路、機能区画を他の3枠と一致させる。内部を見せるためだけに天井を非表示にし、建築や照明を変えず、新しい天光を追加せず、独立したミニチュアにしない。

各枠の**左上角**に、**半透明の黒背景と白文字**で上記の中国語ラベルを一字も変えずに置く。文字サイズ、様式、余白を統一し、主要な風景を覆わず明瞭に読むことができるようにする。記述言語が日本語や他の言語でも、この4ラベルは翻訳・省略・改名しない。他の文字を加えず、大きな枠線で画面を狭めない。

4枠で同じ空間配置と方位基準を使う。固定物の数量、大きさ、位置、向き、素材、経年状態、扉や窓の開閉、照明の点灯、昼夜、天候を維持する。遮蔽に応じて見える数は変わってよい。枠を埋めるために部屋、扉、窓、重要な物、人物を増やさない。屋外は既存の道、建築、主要物で方向を定め、架空の室内構成を当てはめない。

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
16:9横長キャンバス、等大の2×2四枠、各枠も16:9横長。同じ空間と時刻の正面、45度斜側、逆方向、90度垂直俯瞰。[場所 ＋ 年代の質感]、[時間帯]。
前景（[前景の要素]）、中景（[中景の主体空間]）、後景（[後景の奥行き]）の3層に分かれた構図。
出入口（[ドア／通路の位置と様式]）、床（[床の材質と状態]）、壁（[壁の材質と色]）。
[主要な調度品とその固定的な相対位置]。
空間構造は連続し、自己完結的。
[元の光源 ＋ 色温度 ＋ 明暗のコントラスト ＋ 影と反射]、[元の色彩、素材、写真表現、雰囲気]。
各枠左上角に半透明の黒背景と白文字。左上枠「正向视图」、右上枠「45度斜侧视图」、左下枠「反向视图」、右下枠「90度垂直俯视图」。全枠で同じ空間、素材、色彩、実際の光源を維持する。
シーンに人物はいません、空のシーン。映画の質感
```

## 空間構造のルール

空間は**読み取れ、対応が取れ、再利用可能**でなければならない：

- **前景**：フレーミング／遮蔽物（ドア枠、テーブルの角、植物、機器の縁）で奥行きを作る——具体的な要素を1〜2個書く
- **中景**：シーンの主体となる空間と中核の調度品（流れ作業のライン、ベッド、カウンター）
- **後景**：空間の広がり（遠くの壁、窓、廊下、街の輪郭）
- **出入口**：ドア、階段、通路の位置と様式を明確にする（例：「画面左側に鉄のドアが1枚」）。これは後続のカットで人物を出入りさせる演出の根拠となる
- **床と壁**：材質、色、状態を具体化する（例：「コンクリートの床に油の染み」「壁の漆喰が斑に剥がれている」）
- **主要な調度品**：中核となる調度品を2〜4個書き、それらの**固定的な相対位置**を示す（例：「流れ作業のラインが壁沿いに並び、その突き当たりにカウンター」）。調度品同士の左右／遠近の関係は自己完結的であること。物品名を単に列挙しない

## 人物（硬性ルール · 最優先）

**シーン画像にはいかなる人物も出してはならず、シーンそのものだけを残す。**

- プロンプトに人物を描写せず、人物に関連するいかなる内容にも言及しない
- シーン描写（prompt）に登場する人物情報は一律に無視し、プロンプトに書き込まない
- プロンプトの末尾には必ず「シーンに人物はいません、空のシーン」を含める

`prompt`（シーン描写）中の調度品、年代の質感、重要な視覚要素はすべて漏れなく落とし込む；`lighting`（シーンの光影）は具体化する：光源の方向、色温度の寒暖、明暗のコントラスト（例：「頭上の蛍光灯が冷たい白光を放ち、機械の下に硬い影を落としている」）。

## 視点と雰囲気

- 最初の3枠は安定した目線の高さかわずかな俯瞰の広角とし、極端な俯仰、魚眼、傾いた構図は使わない。右下枠のみ指定の90度垂直俯瞰とする。元の前景構図、空間の層、自然な被写界深度、写真の質感を維持する。
- `location` ＋ `time` で時間帯と光線の基調を定める（昼／夜／夕暮れでは光がまったく異なる）
- 雰囲気の語は具体化する：「息苦しい」→「空気が蒸し暑く、光線が暗く沈んでいる」。抽象的な感情語だけを書かない
- 記述はセッションのターゲット言語を使い、指定の4ラベルだけは中国語のまま保持する。無関係な語彙を混ぜない。

## 禁止事項

- いかなる人物——**シーン画像にはいかなる人物も出してはならず、シーンそのものだけを残す**（後ろ姿、シルエット、反射・映り込み、写真の中の人物も含む）
- 指定の4つの中国語ラベル以外の文字、看板の読み取れる文字、透かし、署名
- モーションブラー、動いている物体（シーン参照画像は静止して安定している必要がある）
- 相対位置を示さず調度品のリストを羅列するだけ（空間構造は連続し、自己完結的でなければならない）

## 保存

保存前に、元の構造、調度品、素材、時間、光源方向、寒暖、明暗対比、雰囲気、写真表現が記述されていることを確認する。変更は16:9横長の四分割、4つの視点、指定ラベルだけにする。分析、プレースホルダー、4つの独立したプロンプトを出力せず、1段落にまとめる。

`save_scene_final_prompt` に `scene_id` と `prompt` のみを渡して実際に保存する。**プロジェクト全体のビジュアルスタイルはツールが先頭へ自動注入する**ため、共通の画風プレフィックスを重複させない。シーン固有の照明、色、素材、写真表現は残し、プレフィックスの重複防止を理由に削除しない。
