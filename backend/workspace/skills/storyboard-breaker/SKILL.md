# 分镜拆解

## 输入与任务边界

调用 `read_storyboard_context`，参数为 `{}`，读取当前集剧本、角色、场景、道具和已有分镜。剧本决定人物、台词、主要动作与剧情结果；资产列表决定可用名称和ID。只使用已读取或明确提供的资料。

使用当前会话指定的内容语言；资产正式名称、ID与原文台词不因语言设置而擅自翻译或改名。按本次指定视频模型的特性和时长限制组织提示词；未指定时使用通用写法。模型、画幅、分辨率与风格注入沿用任务配置，不在正文另设固定参数。

本规范处理分镜及 `video_prompt`，不改变角色、场景、道具图片提示词的生成规则。

## 分组与时长

一个分镜段落对应一个视频任务，时长8—15秒，内部包含2—4个子镜头。每个子镜头2—6秒，聚焦一个画面单元（一个动作、一个反应或一个特写）。子镜头可硬切、更换景别、角度或对象，但一组只发生在一个现实场景，使用一个 `scene_id`。

1. 识别【开场】【触发】【高潮】【收尾】等叙事节拍，以及地点转移、规则揭示、情绪爆发和反转。节拍边界强制切段；同一节拍内的子镜头优先归入同一段落，不把一条因果链（铺垫—发生—反应）切散到不同段落。
2. 总量锚定：目标总时长（秒）＝剧本字数÷500×60；预计段落数＝目标总时长（秒）÷12，允许±20%浮动，不明显超出或不足。
3. 按段落功能确定时长，不一刀切：过渡段8—10秒，用于赶路、空镜、环境建立或转场；叙事段10—15秒，用于常规剧情推进与对话；爆点段12—15秒，用于特写、规则揭示、情感爆发或反转，子镜头节奏放慢，单镜可停留4—6秒。
4. 台词预算：`duration ≥ description内台词与旁白总字数÷4.5＋2秒表演余量`。装不下的台词在拆分阶段顺延到下一组，不删改或概括台词。
5. 按动作、视角或对象切换点安排子镜头，同时核对3秒时间段映射与最后余量。镜头数量、动作时间、台词容量和总时长必须同时成立，不为凑组数或镜头数增加剧情。

## 执行与保存

1. 读取上下文，确认整集生成或指定分镜修改。缺少剧本时停止保存，简短说明缺失项。
2. 按原文顺序规划全部分组、子镜头、时长和资产绑定；换场或闪回内容另组处理，不塞入同一视频任务。
3. 逐组设计本组初态、动作、反应及末态。整集重新生成使用本次新结果承接，不沿用旧版站位；仅在明确要求增量修改时参考对应已有分镜。
4. 在 `description` 的各 `【镜头N】` 中写完整画面与台词，再从同一内容生成 `video_prompt`。关键初态、末态及承接信息写进可读取的 `description` 和 `video_prompt`，不能只放在 `result`。
5. 完成检查后调用 `save_storyboards`，每批最多8组。整集重新生成的首批传 `replace_existing: true`；后续批次省略该参数，`shot_number` 顺序递增。只有首批清空旧结果，不在后续批次再次清空。
6. 连续完成本次任务范围内的全部批次，不只保存部分就结束。根据工具返回确认结果；指定分镜修改用 `update_storyboard`，不清空整集。

执行中使用工具调用，不输出规划、分析或长篇解释；批次间不插入叙述。完成后简短确认，阻断或保存失败时说明具体问题和实际进度，不把部分保存称为全部完成。

## 字段与资产绑定

| 字段 | 填写要求 |
|---|---|
| `shot_number` | 按任务范围顺序递增的分镜组编号。 |
| `title` | 3—5字概括本组核心内容。 |
| `time` | 剧情时间及光线描述；原文有具体时分时保留，没有则不冒充原文编造。 |
| `location` | 当前场景完整描述、空间布局和环境细节。 |
| `shot_type` | 主导景别，多景别可写“中景＋特写”。 |
| `angle` | 平视、仰视、俯视、侧面或背面。 |
| `movement` | 主导运镜；各子镜头的具体运动在描述内分别写清。 |
| `description` | 按 `【镜头1】`、`【镜头2】` 逐镜写观众看到和听到的内容，先画面、动作、反应，后台词。画内对白写 `角色名说：「原文台词」`；旁白写 `旁白：原文内容`；其他声音注明准确类型。 |
| `result` | 结尾即时后果、视觉细节、人物位置及持物状态。 |
| `atmosphere` | 光线、色调、环境声音与整体氛围。 |
| `duration` | 本组总时长，满足台词预算、动作与镜头映射。 |
| `scene_id` | 当前段落绑定的场景ID，按下方场景关联规则填写；无匹配时为空。 |
| `character_ids` | 当前段落涉及的角色ID列表，按下方角色绑定规则填写，可以为空或包含多人。 |
| `prop_ids` | 当前段落出现的关键道具ID列表，按下方道具绑定规则填写，可以为空或包含多个道具。 |
| `image_prompt` | 描述第一个子镜头的单帧构图、角色外观、环境和光线，不写多镜头时间轴。 |
| `video_prompt` | 信息头＋逐3秒时间行，采用下述完整内容规范和自然语言表达。 |
| `bgm_prompt` | 简洁明确写“无背景音乐”。 |
| `sound_effect` | 简洁具体的剧情音、动作音和环境声，不只写“紧张”“悲伤”等抽象词。 |

只传工具支持的字段。`description` 与 `video_prompt` 的人物、镜头、动作、台词和结果一致；表演细化不能改变原事实。

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`。
- `location + time` 可明确匹配时，必须回填正确 `scene_id`。
- 不要凭空生成不存在的场景ID；无匹配时置空。
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述。

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择。
- 一个段落可以没有角色，也可以绑定多个角色。
- 只要段落里有明确出场、被看见、发生动作或说话的角色，都应绑定进去，不得遗漏。
- 纯环境段落、空镜、无人物的物件特写可以传空数组。
- 画外发声者的角色绑定不代表该人物实际入镜；不得因为绑定了声音来源就把该人物加入现实画面。

## 道具绑定规则

- `prop_ids` 必须从 `read_storyboard_context` 返回的道具列表（`props`）中选择。
- 道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到该段落。
- 道具特写段落（无角色）也应绑定道具，`character_ids` 可为空。
- 与剧情无关的背景物品、场景陈设不要绑定；没有道具出现的段落传空数组。
- 绑定的道具会作为视频生成的参考图（白底单品图），用于保持道具外观跨段落一致。
- 不得把道具参考图的白底写成剧情背景，也不得因资产列表中存在某项资产就将其加入剧情。

## 视频提示词格式

第一行是独立的信息头，列实际入镜人物、当前场景及实际出现的绑定道具，以句号结尾：`出场人物：@角色名；场景：@场景名；道具：@道具名。` 无人物时填“无”，无道具时省略道具项。随后按3秒输出时间行，每行写成一个连贯的自然段。

- 时间从0开始，连续且无重叠、无空缺；行数为 `ceil(duration / 3)`，最后不足3秒使用实际余量，合计等于 `duration`。
- 每个 `【镜头N】` 对应1—2个连续时间行，顺序一致，不遗漏、不合并、不新增子镜头。跨行继续同一镜头，不重复已经发生的触发、动作或台词。
- 只有镜头编号发生变化才使用“切到／切回”，并交代景别、机位和拍摄主体。首行建立空间，中段推进动作与冲突，末段落到结果及承接状态。
- 每行先写画面与动作，再写该时段的对白、旁白、必要声音和光线；一个时间行围绕一个主要动作单元，动作准备、过程、回应和结果属于同一动作链。
- 不输出“对准谁：”“对准哪里：”“主体动作：”“微表情：”等逐项填表标签；把对应信息写成连续的画面句。声音与光线写在所属时间行，不另立第二套时间轴。
- 不输出未使用模板、空项、“不适用”、外层核对表、制作说明、额外的分镜标题或原样提交命令。不用“同上”“同前”“照旧”“本场既定坐标”替代必要描述。

信息头后、首个时间行前不另加坐标表。首行明确本场空间基准；每个实际子镜头完整表达下列适用信息，可分布于其1—2个时间行。删标签不等于删信息，不要求每个3秒行重复整套静态说明。

## 素材引用与全局约束

使用已绑定资产的精确 `@角色名`、`@场景名`、`@道具名`；场景名称与列表的 `location` 一致。系统负责将 `@名字` 映射为参考图片标记，不自行生成 `@图片N`，不缩写、不添加别名或虚构阶段角色。

每个时间行至少有一个有效引用；实际入镜的角色及明显可见、被使用或特写的关键道具应按出现情况引用。画外发声者不得因此出现在现实画面。台词引号内逐字保留，不替换自然称呼、不插入 `@`。

没有对应资产的普通物品和画外声音使用原名称。`scene_id` 为空时使用剧本地点描述，不伪造场景引用；仍以可用的已绑定人物或道具锚定画面。完全没有可用引用且任务要求参考素材时，报告缺失，不伪造关联。

每条 `video_prompt` 的信息头末尾加入一次全局约束：“无字幕、无背景音乐，保留对白和必要音效；同一现实空间每名人物唯一，不出现克隆人或复制人；不越轴，动作流畅，五官与眼神清晰。”仅输出文字约束，不修改音轨参数。

不得增加剧情、台词、关系或关键物品，不改变说话者、台词类型、动作顺序、镜头顺序和剧情结果。允许补充不改变事实的动作前置、视线、眨眼、呼吸、微表情、微动作、倾听回应和已有环境作用。

## 每个子镜头的完整内容

每个实际子镜头必须在正文中完整表达以下适用信息，不能只作为内部检查项而不写入成品：

1. 实际入镜主体、主要视觉落点和最多一个次要反应落点；不把未入镜人物写成画面主体。
2. 每名面部清晰人物的整体可见神情及对应情绪百分比，并用具体表演体现。
3. 主要动作的触发、视线或呼吸准备、动作前置、过程、峰值及结果；未完成部分顺接，不提前完成下一时段动作。
4. 受刺激者的追视、头部跟随和身体或持物回应；没有跟随对象就不虚构。
5. 各人的自然眨眼、视线、眉眼及嘴角等动态变化；不重复已经写过的同一反应。
6. 与当前姿态、持物、情绪和目标一致的手部或身体微动作；面部特写交代画外持物连续，不强行让手入镜。
7. 当前已存在的环境作用，以及通过本镜画面和声音传达的一项信息重点；不另写剧情分析句。
8. 景别、焦段、机位、单一主要运镜、起始构图、持续时间和最终落点。固定镜头也写清构图重点与保持时间。
9. 清晰入镜人物的实际坐标、姿态、朝向、视线、相互距离、持物及左右手；相关物品的变化、移动结果与下一镜继承状态。
10. 结尾可执行的身体状态和下一行动准备，不以“意识到”“受到震撼”等心理判断代替。
11. 本镜每名发声者的声音资料、发声状态、语气、台词类型及原词；没有台词就不虚构声音。
12. 必要音效、真实光源与方向，以及与项目风格相容的光影与滤镜表现。

多人信息逐人对应。纯环境或道具镜头只写实际适用内容，不新增人物、不填写成串空项。每镜均完整展开，不用省略号或“格式相同”代替内容。

## 空间坐标与跨组承接

生成本组前，按 `shot_number` 定位相邻上一组，判断是否同场景、时间和动作连续。整集首次生成使用本次刚确定的上一组末态；已有分镜重生成读取相邻组 `description`、`video_prompt` 的末镜，不随意使用同场景的其他旧镜头。

连续组继承身份、妆造、位置、姿态、朝向、视线、持物手、未完成动作、面部与呼吸状态，以及天气、门窗、灯光和物品状态。把必要初态具体写入本组首行，不只写“接上一组”。原文明确换场、时间跳跃或状态变化时，按当前剧情重新建立关系，不强行沿用旧站位。

首行用自然语言写完整单场景坐标基准：固定实体原点A0、X轴横向正方向、Y轴纵深正方向、摄影机所在侧与朝向、行动轴线、人物初始坐标与姿态、相互距离、视线和持物，以及相关固定物品、门窗或出口位置。坐标可写 `A(X+0.8米，Y+1.6米)`；没有的实体不得为建坐标而新增。

已有坐标和空间关系必须沿用。缺少米数时可在已知布局内设置近似调度坐标，不能改变已有方位与动作可达性，也不能冒充原文给出的测量事实。同一连续场景不因机位或景别变化重置坐标系，不用画面左右替代真实空间关系。

每个子镜头写明清晰入镜人物的当前坐标和物理状态；同镜跨两行时不重复整组初始坐标，状态有变化就续写。人物移动写清起点、路径、方向、距离和终点；交接物品写清从谁哪只手移到谁哪只手及最终位置。固定物品未变、未参与动作且非视觉重点时，不逐镜重复其坐标。

本组最后时间行完整记录相关人物的末态：位置、姿态、面向及背向关系、视线、间距、持物及左右手、面部和手部状态、天气作用；同时交代变化过的关键物品、门窗、出口、灯光与环境。坐标不变不等于人物停止呼吸或反应。

上一组补充只能填补本组未明确的状态，不能推翻当前剧本和 `description`。关键前序信息缺失或矛盾无法消解时报告问题，不编造已完成承接。已读到下一组时检查新末态是否与其开场冲突，只报告需复核的分镜，不擅自更新其他分镜。

## 表情与自然互动

每名五官清晰可辨的人物在每个实际子镜头中具有自然眨眼、明确视线目标或变化、一项眼睑／瞳孔／眉眼变化，以及一项嘴角／鼻翼／下颌变化。眨眼由刺激、视线调整、呼吸或开口准备带出，不固定在镜头开头，不按每3秒重复，也不让多人同步。原文明示昏迷等无法做出正常反应的状态时，遵守剧情，不强加动作。

反应遵循“刺激→视线追向来源→短暂停顿与自然眨眼→局部面部变化→手部或身体回应→开口或行动”。不用机械写满每一步，但触发、过程和结果必须清楚。

说话者开口前至少有一项自然准备，口型只同步本人台词。倾听者至少有两项不同的自然反应，如追视并轻眨、转眼后头部微转、吞咽并收紧手指；不得因无台词而静止或同步他人口型。

每镜逐人保留“整体可见神情＋情绪百分比”，融入自然句，例如“@小明受用好奇（情绪94%）”。不得只列数字，也不得以文字强弱替代必需百分比。百分比表示该神情的外显强度与明确程度：20%—40%轻微流露，41%—70%清晰可辨，71%—90%强烈外显，91%—100%充分显现；高值可用于平静、笃定、克制或礼貌，不一律解释为暴怒或大哭。

整体神情与动态微表情各司其职，不重复同句。可写受用好奇、礼貌平静、警觉迟疑、慌乱心虚、错愕戒备、隐忍委屈、克制愤怒、欣慰心疼；相互冲突的神情必须有转变过程。眉眼、瞳孔、嘴角、呼吸和泪水变化必须有刺激来源，不随机增加大哭或暴怒。

微动作由刺激、姿态、持物、情绪、行动目标和上一镜手部状态共同决定。手部可见时写独立、合适的动作；面部特写使用吞咽、呼吸、下颌或肩颈变化，不破坏景别。画外手部重新入镜时，持物及左右手必须承接。

多人眨眼、转头、点头和手部动作自然错开，不复制同一种小动作。禁止空洞直视、眼球固定、无依据正对镜头发呆、僵硬站立、机械点头、无触发反复搓手／握拳／捏衣角；不得用“安静听着”“保持不动”作为唯一表演。

## 动作、摄影与环境

重要动作完整表达“触发→准备或发力→过程→峰值→结果→对方反应→末态”。例如已安排的起身要表现重心转移和身体上升，不只写站立结果；受刺激者应有追视、眨眼、面部及适用的手部或身体反应。不得为了补足链条新增推搡、拥抱、打斗、挡路等重大动作。

每个子镜头只采用一种主要运镜，可选固定、推、拉、摇、横移、升、降、跟、环绕、甩镜或手持；人物移动不算第二种运镜。已有运镜不能在提示词转换阶段改掉，未明确焦段等参数时作不改变镜头事实的调度补充。

平稳叙事由中景到近景或特写；信息揭示表现关键物后接人物反应；动作冲突交代主体、结果与受刺激者。初次设计相邻近似机位的景别变化时，角度至少变化30度，保持同侧不越轴；无特殊目的不从远景直接跳到大特写。人物移动优先跟镜；多人对白不能长期只拍说话者。已确定的镜头数量、顺序和切点不在转换阶段重排。

每镜写符合现有条件的环境作用，不为填内容增加风、雨、灰尘、雾或水花。没有动态环境时可写既有日光方向、衣物随动作轻摆或接触状态，不机械重复“微风吹动发丝和衣角”。

- 雨景区分伞、屋檐等遮挡范围及暴露部位；湿发贴肤、衣料加深变重、雨水流动和滴落连续，走动才产生相应水花；擦去的雨水可再积聚，湿发不按干发飘扬，湿衣不突然变干。
- 晴天和有风环境保持光向与风向，强风、微风幅度不同；人物进入阴影时，亮度随路径变化，不凭空增加气流。
- 夜景写清实际主光源，提供符合场景的柔和补光，使五官和眼神可辨；经过光源时明暗连续。
- 寒冷、风雪、雾气仅在已有环境支持时描写；白气、肩颈和手部反应符合温度，雾气不遮没主要人物五官。
- 室内门窗、灯光、电视和物品状态连续；关闭的电视不继续发光发声。杯水等运动逐渐衰减，无气流来源不让衣摆发丝持续飘动。

除原文明确安排外，本组末镜不新增转场、甩镜、转黑或定格；继续未完成动作，不重演已完成动作。

## 台词与配音

逐字保留对应子镜头的台词，人物、类型和顺序不变，每句只出现一次。画内对白写 `角色名说：「原文台词」`，旁白写 `旁白：原文内容`；语气和动作写在引号外，不改原词、不把自然称呼换成资产名称。

在每个有发声的子镜头中，逐人写出听感年龄、音域、核心音色、当前身体状态与发声目标，以及音量、语速、气息、尾音和情绪；与本镜原文台词自然连接，不输出填表标签。固定声音描述控制在15—30字符，至少包含年龄感、音域、核心音色；同人跨镜复用，不随换装自行更换。只有声音资料明确变化时才改变。

资料不足时根据已知年龄和人物资料作保守声音设计描述，不声称已绑定真实声音。有真实VoiceID时每个对应发声镜头准确注明；没有就省略，不虚构、猜测或填写“待定”“待绑定”。VoiceID不放进实际入镜人物的信息头。

每个发声子镜头写明约每秒x字的语速，数值依据台词字数和分配的口播时间估算；总容量仍服从4.5字/秒加2秒表演余量的预算，不加入固定6—7字/秒要求，不以提速掩盖装不下的台词。长句按自然分句在同一子镜头的连续时间行分配，不截断词语、不重复、不换发声者。相邻同人同镜台词可连续表达，不合并不同角色轮次、不提前使用后组台词。

说话者口型同步本人台词；OS期间人物闭唇；旁白、电话音、广播、门外音、电视播报说明来源，现实人物不代替画外声音对口型。回忆声音不自动生成闪回画面。音效只保留原文声音、动作必要音与必要环境声，持续声音跨时间行连续，不每3秒重新起音。

## 光影、风格与Q版

每个子镜头明确实际光源及方向，光线来自 `atmosphere` 和场景资料，并服从已知项目风格。五官与眼神清晰，避免死黑人脸、过曝、光效遮脸、柔焦抹掉眼睑或嘴角、无因改变光源方向。不重新拼接整段项目风格，不阻止系统自动注入。

与当前环境及项目风格相容时，选择合适的光影编号、名称和滤镜，随光源写进自然句；无相容选项不强套，不为某个编号改变场景事实：

T1柔光漫射甜光；T2暖金色侧逆光；T3星月冷暖混合光；T4窗边丁达尔甜光；T5烛火灯火暖柔光；T6朦胧梦幻柔光；T7清晨奶油柔光；T8蝴蝶美容柔光；T9户外晴天漫射甜光；T10雨夜甜宠柔光；T11雪天甜宠柔光；T12车内夜景甜宠光。

滤镜：梦幻柔焦柔光、日系暖阳胶片、粉橘浪漫柔光、薄雾清透莫兰迪、黄金黄昏丁达尔、韩漫冷白奶油、樱花淡粉水彩、月光银辉、CCD奶杏、青空森系薄雾、蜜桃牛奶柔光、珍珠柔光、春日清透薄纱。

电影级光影和丰富细节须与正式风格相容；“24K蓝光画质”仅在项目明确要求该表述时保留，不把它当作实际分辨率参数或已验证画质。

仅在原文且当前分镜明确安排Q版时描写头大身小、圆润立体的3D人物，动作有重心与弹性，视线、眨眼、表情和手部连续，环境沿用本场。没有Q版则不添加，也不输出“Q版：无”等空项。

## 保存前检查

1. 台词、声音类型、说话者、原词与顺序正确，主要动作和结果无新增、遗漏或重复。
2. 子镜头与3秒时间行对应，切镜点正确，时间连续且合计等于 `duration`；台词与动作可容纳。
3. 一个场景，ID及 `@` 引用来自可用资产；实际入镜者与画外声音区分，单个人物不重复生成。
4. 每个子镜头的拍摄重点、逐人表情及百分比、完整动作、跟随反应、微表情、微动作、环境、信息点、运镜、空间末态和声音均写入适用内容，不以内部检查代替成品表达。
5. 组首状态有依据地继承前组末态，逐镜坐标、朝向、视线、姿态、持物手、动作和环境连续；原文换场或跳时不错误承接。
6. 说话者与倾听者都有自然反应，口型正确，多人动作错峰；纯面部特写没有为手部要求改变构图。
7. 每镜一种主要运镜，焦段、机位、起点、时间和落点清楚；音色有据且连续，光源与滤镜不推翻项目风格。
8. 输出为信息头＋自然语言时间行，无导演填表标签、外层核对文档、空模板、占位符或与任务无关内容；语言符合当前会话要求。

保存的 `video_prompt` 不超过3600字符，不设凑字数下限。精简时先删重复动作、静态坐标、情绪解释和修饰词，不删原文台词、重要过程、逐人必需表演与承接信息。没有实际计数结果不虚报精确字符数；检查失败先修正，无法在既定镜头与时长内修正时报告具体冲突，不冒充完成。

## 输出写法

以下只示范一个时间行。假设该子镜头已经安排两人在院中对话；示例人物、物品和数字不自动带入其他项目。完整任务仍应包含信息头和全部时间行。

```text
3-6秒：切到50mm东侧平视中景，固定拍摄3秒，构图以@顾野抬起的左手为主，次落@马婆子的面部，两者始终入镜。@顾野站在A(X-0.5米，Y+1.9米)，面向坐在A(X+1.3米，Y+1.9米)的@马婆子，相距1.8米，右手握稳@缰绳；他听见既有质疑后转眼看向她，轻眨并收紧下颌，露出咬牙强硬的神情（情绪94%），左手从腰侧抬起指向村路，衣袖随动作轻摆。@马婆子追视他的手势后才抬眼看向他，错开眨眼，眉心收紧、嘴唇微张，慌乱心虚（情绪91%），左手撑地时手指收紧，右手仍扣住衣摆。结尾两人的坐标与持物手未变，左手指向保持，马婆子仰头准备回应。衣料摩擦和既有环境声连续，东南侧漫射日光照清两人的五官，固定构图最终落在手势与受惊反应上。
```

## 场景四视图参考规则
当引用的场景资产图片为四视图（包含正向视图、45度斜侧视图、反向视图、90度垂直俯视图）时，必须将其理解为同一场景的多角度空间参考，用于理解场景布局、门窗位置、家具摆放、人物空间关系及镜头方向。生成视频时，只根据当前分镜描述呈现所需的单一连续画面，不得复刻四宫格布局、视图标签或多视图拼接效果；不得擅自改变场景空间结构、镜像场景或因切换视角而改变场景布局。镜头切换必须严格依据分镜中的【镜头N】安排，不得因为场景参考图包含多个视角而额外增加镜头或转场。
